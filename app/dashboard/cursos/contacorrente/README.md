# Curso Conta Corrente — TreinExpresso

## Instalação

1. Copie a pasta `app/cursos/contacorrente` para o seu projeto.
2. A rota ficará disponível em:
   `/cursos/contacorrente`
3. O arquivo utiliza Tailwind CSS, assim como o simulador original.
4. O simulador foi incorporado dentro da própria `page.tsx`.
5. O quiz exige 70% de aproveitamento.

## Conteúdo incluído

- Regras para abertura de Conta Corrente
- Orientação sobre menores de idade e Next Joy
- Documentos aceitos
- Senha de 4 números
- Senha de 6 dígitos
- Jornada completa no tablet
- Simulador interativo
- Quiz com 12 questões
